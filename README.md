# 🧠 Quiz

Um quiz interativo desenvolvido como **projeto prático de estudo e evolução em desenvolvimento Frontend**, com foco principalmente no aprimoramento de **lógica de programação, raciocínio na estruturação de aplicações e desenvolvimento da solução do início ao fim**.

A ideia deste projeto foi utilizar o desenvolvimento da aplicação como um exercício para praticar a capacidade de **pensar na estrutura da aplicação, organizar informações, criar regras de negócio e transformar essas ideias em código funcional**.

---

### 🎯 Objetivo do Projeto

Este projeto foi desenvolvido com o objetivo de praticar e aprimorar habilidades importantes para o desenvolvimento de aplicações Frontend, principalmente:

* Raciocínio lógico;
* Estruturação de aplicações;
* Criação e controle de fluxos;
* Organização de dados e informações;
* Implementação de regras de negócio;
* Manipulação de elementos da interface;
* Desenvolvimento de uma interface responsiva;
* Estruturação e estilização de interfaces com Tailwind CSS.

O desenvolvimento do quiz serviu como um exercício para **pensar antes de codificar**, definir como as informações seriam organizadas e determinar como cada parte da aplicação deveria se comportar.

---

### 🎮 Como Funciona

Neste projeto, desenvolvemos um quiz que abrange tópicos de conhecimento geral. O quiz é composto por uma série de perguntas de múltipla escolha que irão desafiar seu conhecimento. Cada pergunta tem opções de resposta, e você deve selecionar a opção correta. No final do quiz, você receberá uma pontuação com base no número de respostas corretas.

Durante o desenvolvimento foram trabalhados diferentes fluxos e condições para controlar o comportamento da aplicação, como:

* Controle da pergunta atual;
* Renderização das alternativas;
* Validação das respostas;
* Contabilização de acertos;
* Avanço entre perguntas;
* Atualização dinâmica da interface;
* Finalização do quiz;
* Exibição do resultado.

---

### 🧩 O Principal Desafio

A construção do quiz exigiu pensar em questões como:

> Como estruturar o projeto;

> Como dividir responsabilidades;

> Como representar os dados;

> Como controlar o estado;

> Como implementar as regras de negócio;

> Como lidar com eventos;

> Como atualizar a interface;

> Como persistir informações;

> Como tornar a aplicação responsiva;

> Como manter o código organizado e preparado para evolução.

Esses problemas foram transformados em **regras, estruturas de dados, funções e fluxos de execução**, tornando o projeto um exercício prático de lógica e desenvolvimento.

---

### 🛠️ Tecnologias Utilizadas

#### HTML

Utilizado para construir a estrutura e a semântica da aplicação.

#### Tailwind CSS

Utilizado para a estilização da interface, criação do layout e desenvolvimento de uma experiência responsiva.

#### JavaScript

Responsável principalmente pela lógica da aplicação, controle do fluxo do quiz, processamento das respostas e gerenciamento do estado da aplicação.

#### jQuery

Utilizado para manipulação do DOM, eventos e interação dinâmica com os elementos da interface.

### 🚀 Como Executar

Como o projeto utiliza HTML, CSS, JavaScript e jQuery no Frontend, não é necessário um backend para executá-lo.

### 1. Clone o repositório

```bash
git clone https://github.com/XsJota/quiz.git
```

### 2. Acesse o projeto

```bash
cd Quiz
```

### 3. Execute

Abra o arquivo:

```text
index.html
```

em seu navegador.

Também é possível utilizar uma extensão como **Live Server** para executar o projeto durante o desenvolvimento.
